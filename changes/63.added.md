Progress dots: `view.Views.Progress` renders a run's steps as a row of coloured dots for a host's own page about the thing the run is about (bytestone-scan's batch page), one per step in the order the run's revision recorded, green completed, red failed, amber waiting or running, yellow cancelled, white not run, each titled with the step and its status, the row linking to the instance page.
