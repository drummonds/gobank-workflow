A definition is drawn twice, across in one row (`diagram.Across`, `<type>.svg`) and down in one column (`diagram.Down`, `<type>.down.svg`), and the pages show the one that fits the screen, down on a phone, through a `<picture>` media query. The four-column grid goes: d2 fills a grid column first, so a long definition read downwards with diagonal jumps, and a grid cell cannot take the loop arrow of a one-at-a-time step. In a row or a column every edge is routed around the boxes. `diagram.Definition` and `diagram.Instance` take the direction; the demo's `defd2` writes both files. Breaking for hosts calling `diagram`
